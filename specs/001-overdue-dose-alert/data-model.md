## TypeScript Domain Types

### Core Value Types

```typescript
// Branded types prevent accidental mix-ups between domain IDs
type DoseId    = string & { readonly __brand: 'DoseId' };
type PatientId = string & { readonly __brand: 'PatientId' };
type ActorId   = string & { readonly __brand: 'ActorId' };
type EventId   = string & { readonly __brand: 'EventId' }; // UUID v4

// The only valid alert state transitions are strictly left-to-right:
// INACTIVE → ALERT_ACTIVE → ALERT_ESCALATED → ACKNOWLEDGED
// (ALERT_ACTIVE may skip directly to ACKNOWLEDGED)
type AlertStatus =
  | 'INACTIVE'
  | 'ALERT_ACTIVE'
  | 'ALERT_ESCALATED'
  | 'ACKNOWLEDGED';
```

### DoseEvent

```typescript
/** Immutable record received from the upstream scheduling system. */
interface DoseEvent {
  readonly doseId:        DoseId;
  readonly patientId:     PatientId;
  readonly medicationName: string;
  readonly scheduledAt:   Date;   // UTC; injected, never derived from system clock
}
```

### AlertRecord (Discriminated Union)

```typescript
/**
 * Full lifecycle state of an alert for a single DoseEvent.
 * Each variant is append-only — records are never mutated in place.
 * @satisfies REQ-003, REQ-005
 */
type AlertRecord =
  | {
      readonly kind:    'INACTIVE';
      readonly doseId:  DoseId;
    }
  | {
      readonly kind:        'ALERT_ACTIVE';
      readonly doseId:      DoseId;
      readonly patientId:   PatientId;
      readonly medicationName: string;
      readonly scheduledAt: Date;
      readonly alertedAt:   Date;   // injected now at time of detection
    }
  | {
      readonly kind:           'ALERT_ESCALATED';
      readonly doseId:         DoseId;
      readonly patientId:      PatientId;
      readonly medicationName: string;
      readonly scheduledAt:    Date;
      readonly alertedAt:      Date;
      readonly escalatedAt:    Date; // injected now at time of escalation
    }
  | {
      readonly kind:             'ACKNOWLEDGED';
      readonly doseId:           DoseId;
      readonly patientId:        PatientId;
      readonly medicationName:   string;
      readonly scheduledAt:      Date;
      readonly alertedAt:        Date;
      readonly escalatedAt?:     Date; // present only if escalation occurred first
      readonly acknowledgedAt:   Date;
      readonly acknowledgedBy:   ActorId;
    };
```

### AuditEntry

```typescript
/**
 * Immutable record written to the append-only audit log for every state
 * transition and every rejected action. Never updated or deleted.
 * @satisfies REQ-006, REQ-007
 */
interface AuditEntry {
  readonly eventId:    EventId;        // UUID v4, generated by repository adapter
  readonly timestamp:  string;         // ISO 8601 UTC, e.g. "2026-04-20T14:32:00.000Z"
  readonly actorId:    ActorId;        // non-empty; "system" for automated actions
  readonly transition: string;         // canonical "FROM_STATE → TO_STATE"
  readonly doseId:     DoseId;
  readonly payload:    Readonly<Record<string, unknown>>; // serializable snapshot
}
```

### AlertThresholdConfig

```typescript
/**
 * Validated at startup; never read from environment at runtime.
 * @satisfies REQ-011, REQ-012
 */
interface AlertThresholdConfig {
  readonly alertThresholdMinutes:     number; // positive integer, default 15
  readonly escalationThresholdMinutes: number; // positive integer, default 10
}
```

### Effect Descriptors (Side-Effect Algebra)

```typescript
/**
 * Pure functions return Effects instead of executing I/O directly.
 * The application shell interprets and executes these.
 * @satisfies REQ-002, REQ-004, REQ-009
 */
type Effect =
  | { kind: 'EMIT_ALERT_ACTIVE';     record: Extract<AlertRecord, { kind: 'ALERT_ACTIVE' }> }
  | { kind: 'EMIT_ALERT_ESCALATED';  record: Extract<AlertRecord, { kind: 'ALERT_ESCALATED' }> }
  | { kind: 'EMIT_SYSTEM_ALERT';     error: Error; context: string }
  | { kind: 'WRITE_AUDIT';           entry: AuditEntry }
  | { kind: 'PERSIST_ALERT_RECORD';  record: AlertRecord };
```

## PostgreSQL Schema

### `dose_events`

```sql
CREATE TABLE dose_events (
  dose_id          TEXT        NOT NULL PRIMARY KEY,
  patient_id       TEXT        NOT NULL,
  medication_name  TEXT        NOT NULL,
  scheduled_at     TIMESTAMPTZ NOT NULL  -- always stored as UTC
);
-- The application role has SELECT only; dose events are owned by the
-- upstream scheduling system and written via a separate service account.
```

### `alert_snapshots`

```sql
CREATE TABLE alert_snapshots (
  dose_id          TEXT        NOT NULL PRIMARY KEY,
  status           TEXT        NOT NULL
    CHECK (status IN ('INACTIVE','ALERT_ACTIVE','ALERT_ESCALATED','ACKNOWLEDGED')),
  patient_id       TEXT,
  medication_name  TEXT,
  scheduled_at     TIMESTAMPTZ,
  alerted_at       TIMESTAMPTZ,
  escalated_at     TIMESTAMPTZ,
  acknowledged_at  TIMESTAMPTZ,
  acknowledged_by  TEXT,
  updated_at       TIMESTAMPTZ NOT NULL DEFAULT now()
);
-- Application role: INSERT, SELECT, UPDATE (no DELETE).
-- UPDATE is restricted to the status forward-transition sequence via a
-- CHECK CONSTRAINT or trigger; never allows regression to a prior status.
```

### `audit_log`

```sql
CREATE TABLE audit_log (
  event_id    UUID        NOT NULL PRIMARY KEY DEFAULT gen_random_uuid(),
  timestamp   TIMESTAMPTZ NOT NULL,          -- supplied by application in UTC
  actor_id    TEXT        NOT NULL CHECK (actor_id <> ''),
  transition  TEXT        NOT NULL,
  dose_id     TEXT        NOT NULL,
  payload     JSONB       NOT NULL
);
-- Application role: INSERT, SELECT only.
-- No UPDATE or DELETE granted — enforced at database level.
-- Partitioned by month for query performance at scale.
CREATE INDEX audit_log_dose_id_idx ON audit_log (dose_id);
CREATE INDEX audit_log_timestamp_idx ON audit_log (timestamp DESC);
```

## State Transition Table

| Current State    | Stimulus                        | Next State       | Effect(s) emitted                                    |
|------------------|---------------------------------|------------------|------------------------------------------------------|
| `INACTIVE`       | detect (elapsed ≥ threshold)    | `ALERT_ACTIVE`   | `WRITE_AUDIT`, `PERSIST_ALERT_RECORD`, `EMIT_ALERT_ACTIVE` |
| `INACTIVE`       | detect (elapsed < threshold)    | `INACTIVE`       | _(none)_                                             |
| `ALERT_ACTIVE`   | detect (any)                    | `ALERT_ACTIVE`   | _(none — duplicate suppressed, REQ-003)_             |
| `ALERT_ACTIVE`   | escalate (unacked ≥ esc. threshold) | `ALERT_ESCALATED` | `WRITE_AUDIT`, `PERSIST_ALERT_RECORD`, `EMIT_ALERT_ESCALATED` |
| `ALERT_ACTIVE`   | escalate (unacked < esc. threshold) | `ALERT_ACTIVE` | _(none)_                                           |
| `ALERT_ESCALATED`| escalate (any)                  | `ALERT_ESCALATED`| _(none — duplicate suppressed, REQ-005)_             |
| `ALERT_ACTIVE`   | acknowledge (valid actorId)     | `ACKNOWLEDGED`   | `WRITE_AUDIT`, `PERSIST_ALERT_RECORD`                |
| `ALERT_ESCALATED`| acknowledge (valid actorId)     | `ACKNOWLEDGED`   | `WRITE_AUDIT`, `PERSIST_ALERT_RECORD`                |
| `ACKNOWLEDGED`   | acknowledge (any)               | `ACKNOWLEDGED`   | _(idempotent no-op)_                                 |
| any              | acknowledge (empty actorId)     | unchanged        | `WRITE_AUDIT` (rejection record, actorId="system")   |
| any              | internal error                  | unchanged        | `EMIT_SYSTEM_ALERT`, `WRITE_AUDIT`                   |

## Validation Rules

| Field                          | Rule                                                   |
|--------------------------------|--------------------------------------------------------|
| `AlertThresholdConfig.alertThresholdMinutes` | Positive integer (> 0); fail startup if invalid |
| `AlertThresholdConfig.escalationThresholdMinutes` | Positive integer (> 0); fail startup if invalid |
| `AuditEntry.actorId`           | Non-empty string; "system" for automated actions       |
| `AuditEntry.timestamp`         | ISO 8601 UTC string with `Z` suffix                    |
| `AcknowledgeRequest.actorId`   | Non-empty string; rejection + audit log if empty       |
| `DoseEvent.scheduledAt`        | UTC Date; must not be in the future at creation        |
| `AlertRecord` transitions      | Typed errors thrown for invalid forward-transitions;   |
|                                | no regression (ACKNOWLEDGED → ACTIVE is compile error) |
